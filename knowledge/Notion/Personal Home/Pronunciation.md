# Three rules for S/Z endings

## Rule \#1

If a word ends in a sound that is unvoiced (such as P,T,K,F), you add an  
unvoiced /S/  

## Rule \#2

If a word ends in any of these sounds: ‘s,z,sh,ch,or dg (j)’  
when adding an ‘S’ ending, add...  
_IZZZZZZ_

## Rule \#3

If a word ends in a vowel sound (like the word _Tree_) or a voiced consonant (like  
the word  
_Game_), then when you add an ‘S’, continue the voicing throughout  
the entire word, and it should become a voiced ZZZZ.
