equivalence: tương đương

Compose: gọp nhiều unicode code point thành một

Decompose: tách thành nhiều unicode code point

  

canonically equivalent: hiển thị giống nhau nhưng unicode code point khác nhau

compatibility equivalence: Hiển thị khác nhau nhưng unicode code point giống nhau

> Unicode also defines a “compatibility equivalence” to equate characters that represent the same characters, but may have a different visual appearance. For example, the superscript digit ‘⁹’ and the regular digit ‘9’ are equivalent in this form.

> Unicode cũng định nghĩa “sự tương đương về khả năng tương thích” để đánh đồng các ký tự đại diện cho các ký tự giống nhau, nhưng có thể có hình thức trực quan khác
