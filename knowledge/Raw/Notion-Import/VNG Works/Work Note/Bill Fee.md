# Overview

Số tiền thanh toán = giá trị đơn hàng + Phí nguồn tiền + phí dịch vụ.

|   |   |
|---|---|
|Name|Description|
|SOF fee|Phí nguồn tiền, khi apply nguồn tiền sẽ bị tính phí tương ứng|
|Service Fee|Phí user, bị charge khi thanh toán với app tương ứng.|
