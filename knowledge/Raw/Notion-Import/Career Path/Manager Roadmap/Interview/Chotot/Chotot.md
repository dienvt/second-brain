# Process

- [x] 1st round: với 1 or 2 Backend expert (hỏi về nền tảng Software/ coding challenge/ hỏi về hệ thống, kiến thức về industry)
    - [x] Hỏi về kinh nghiệm làm việc (15’)
        - [x] Khó khăn vào thách thức
    - [x] Fundamental (15’)
        - [x] Thread vs process
        - [x] Hỏi tại sao thread lại có thẻ truy cập vùng nhớ chung nhưng mà process thì không
        - [x] Context switching là gì và tại sao chi phí nó đắt
        - [x] Sẵn thì hỏi luôn về Goroutines, giải thích Concurrency vs parallel
        - [x] Hỏi luôn về HTTP vs HTTPS làm sao mà nó trao đổi key với nhau. tại sao https lại secure hơn http
        - [x] Hỏi về data structure, array vs linked list
    - [x] Câu hỏi coding challenge (30’)
        - [x] Check {}()[] có valid hay không
    - [x] Industry (30’)
        - [x] Index là gì và tại sao cần index, pros and cons
        - [x] Hỏi nhiều về JWT, tại sao nó lại được sử dụng nhiều.
- [ ] 2nd round: nói chuyện với Head of Engineering người Việt
- [ ] 3rd round sẽ gặp HRD 30' để trao đổi về môi trường, văn hóa và phúc lợi. Sau đó lunch với peers hoặc gặp online nếu khác location.
