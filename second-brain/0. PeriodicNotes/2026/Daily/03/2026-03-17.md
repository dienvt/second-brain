 1. Envelope storage bytes + total count (uses occurred_at)
```sql
  SELECT
    SUM(LENGTH(content)) + SUM(LENGTH(subject)) AS storage_bytes,
    COUNT(*)                                     AS resource_count
  FROM envelopes
  WHERE occurred_at >= ? AND occurred_at <= ?;
```

  2. Sent email count (only non-imported sent emails)
```sql
SELECT COUNT(*) AS sent_count
  FROM envelopes
  WHERE is_imported = false
    AND occurred_at >= ?
    AND occurred_at <= ?
    AND type = 'ENVELOPE_TYPE_SENT';
```

  ▎ This is what gets set as Envelopes.ResourceCount in the response — not the total count above.

  3. Attachment storage bytes + count (uses created_at)
```sql
 SELECT
    SUM(file_size) AS storage_bytes,
    COUNT(*)       AS resource_count
  FROM attachments
  WHERE created_at >= ? AND created_at <= ?;
```
