# Tree traversal 

Algorithm In-order(tree)
Traverse the left subtree, i.e., call In-order(left->subtree)Visit the root.Traverse the right subtree, i.e., call In-order(right->subtree)


_Depth First Search or DFS_
* Inorder Traversal: **Left -> Root -> Right**
* Preorder Traversal: **Root -> Left -> Right**
* Postorder Traversal: **Left -> Right -> Root**

_Level Order Traversal or Breadth First Search or BFS_
* Boundary Traversal
* Diagonal Traversal
